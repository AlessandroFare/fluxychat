## FluxyTrack (3.1) — Full Implementation

**Schema migration** (`apps/worker/db/0151_fleet_tracking.sql`):
- `gps_raw` — raw GPS points (7gg retention, PK vehicle_id+timestamp)
- `gps_aggregated_5min` — 5min aggregations (90gg retention)
- `fleet_vehicles` — vehicle registry (status: online/offline/idle/en_route)
- `fleet_trips` — trip management (pending/active/completed/cancelled)
- `fleet_geofences` — geofence zones with center+radius
- `fleet_geofence_events` — enter events

**Worker library** (`apps/worker/src/lib/fleet-tracking.js`):
- `haversine(lat1, lon1, lat2, lon2)` — returns meters
- `pointInGeofence()` — Haversine-based geofence check
- GPS ingestion with auto-aggregation + geofence detection
- Full CRUD: vehicles, trips, geofences, GPS history/current positions

**Worker routes** (`apps/worker/src/routes/fleet-tracking-http.js`):
- `POST /fleet/gps` — ingest GPS point
- `GET /fleet/gps/current` — all online vehicles with last positions
- `GET /fleet/gps/history?vehicleId=X&from=Y&to=Z`
- `GET/POST /fleet/vehicles`
- `PATCH /fleet/vehicles/:id`
- `GET/POST /fleet/trips` + `PATCH /fleet/trips/:id` (status transitions)
- `GET/POST /fleet/geofences`

**SDK methods** (`packages/sdk/src/index.ts`, inseriti prima del closing brace della classe):
- `ingestGps()`, `getFleetPositions()`, `getGpsHistory()`
- `listFleetVehicles()`, `createFleetVehicle()`, `updateFleetVehicle()`
- `listFleetTrips()`, `createFleetTrip()`, `updateFleetTripStatus()`
- `listFleetGeofences()`, `createFleetGeofence()`

**Dashboard** (`apps/dashboard/app/fleet/page.tsx`):
- Full fleet page with Leaflet map (dynamic import, SSR disabled)
- 3 tabs: Vehicles | Trips | Geofences
- Create dialogs for vehicles, trips, geofences

**Nav** (`apps/dashboard/app/components/console-nav.ts`):

**Key decisions:**
- Haversine algorithm (gratis, no API costs) per ROADMAP.md decisione architetturale #9

- Fleet ID = project ID (no multi-fleet per progetto per ora)
