Scope: `apps/worker` (lib, routes, durable-objects, workflows), `apps/ai-agent`, `apps/dashboard`, `packages/sdk`, `packages/ui`. ~110K LOC.
Method: 5 parallel deep-dive reviews, findings grounded to `file:line`.

Production status: rolled back to worker version `c0ca1869-9f6e-46e8-83d2-e0d5415ba92b`; `/health` green (db/DO/kv/r2 connected).

## CRITICAL (exploitable now — fix before next deploy)

1. **SAML signature verification bypassed (missing `await`)** — `routes/identity-access-http.js:114`
   `parseSamlAssertion` is async but called without `await`; `assertion` is a Promise so the validity check passes truthy. Any forged `SAMLResponse` mints a valid project JWT for any user. → `const assertion = await parseSamlAssertion(...)` and reject non-valid.

2. **Admin auth accepts unsigned/forged JWTs** — `routes/identity-access-http.js:344-365` (`verifyAdmin`)
   Decodes JWT with `atob` and never verifies the HMAC ("no verification needed for admin check"). Forge `{tid, roles:["owner"]}` → full admin on SAML config, SCIM, 2FA for any tenant. → use `verifyJwtAndGetContext` + `hasAnyRole`.

3. **`/admin/companions/*` — no auth + cross-tenant IDOR** — `routes/companion-http.js` (no auth) + `lib/ai-companions.js:45,59`
   No JWT/admin gate; `getCompanion/updateCompanion/deleteCompanion` query `WHERE id = ?` only. Anyone reads/edits/deletes any tenant's AI companions + memory. → add admin auth + `AND project_id = ?`.

4. **`/rooms/{id}/objects` — unauthenticated + cross-tenant IDOR** — `routes/business-objects-http.js:15-108` + `lib/business-objects.js:58,76`
   No JWT, no room/project check; by-id object CRUD. → member/admin auth + `canAccessRoom` + project scoping.

5. **Public file download has no authorization** — `routes/public-http.js:255-287` (`GET /attachments/...`)
   Unauthenticated fetch of any object key; no project/membership check (traversal is blocked, authz is not). → require JWT + match `auth.projectId` to key prefix.

6. **SAML XML Signature Wrapping** — `lib/sso-saml.js:600-612`
   Verifies `<SignedInfo>` against the cert but never checks the `<Reference>` `DigestValue` vs the element; identity is regex-scraped from the whole doc. Classic XSW → inject attacker NameID. → verify each Reference digest over the canonicalized referenced node; read claims only from the signed node.

7. **SAML config hijack cross-tenant** — `lib/sso-saml.js:99` (`UPDATE saml_configurations ... WHERE id = ?`)
   Overwrite any tenant's `idp_certificate`/`idp_entity_id` → SSO takeover. → `WHERE id = ? AND project_id = ?`.

8. **ai-agent SSRF via DB-controlled provider URLs + injected context** — `apps/ai-agent/src/handlers.js:184,246,312`
   `provider`/`model` from DB row, body attacker-influenced; combined with #9 a forged webhook drives `fetch()` and can exfiltrate the bearer/API key. → allowlist provider hosts; never send creds to non-allowlisted origin; treat `provider` as a validated enum.

9. **ai-agent webhook signature is fail-open** — `apps/ai-agent/src/agent.js:63-86`
   `webhookSecret = env.WEBHOOK_SECRET || env[WEBHOOK_SECRET_<projectId>]`; pick a `projectId` with no secret → `if (webhookSecret)` skipped → unverified request accepted. → resolve secret from a trusted source independent of the body; hard-fail when no valid signature.

## HIGH

10. **Room DO uses non-hibernatable WebSockets** — `durable-objects/room-do.js:328,420-432`
    Uses `webSocket.accept()` + `addEventListener` instead of `state.acceptWebSocket()`. On eviction all in-memory connection state (`clients`, `userIds`, counts, `activeStreams`) is lost → wrong presence/counts, orphaned `streaming:true` rows. → migrate to Hibernatable WebSocket API.

11. **`recovered:` presence entries leak unboundedly** — `room-do.js:413-416`
    Up to 100 `userIds.set("recovered:…")` per connect, never removed on close → unbounded growth. → recompute recovered presence separately, don't accumulate in `userIds`.

12. **Rate limiter off-by-one (limit+1 per window)** — `ip-rate-limiter-do.js:32-44`, `room-do.js:1533-1546`
    Check is `count >= limit` after creating bucket at `count:1`; lets one extra through. → reject when `count + 1 > limit`.

13. **Ephemeral state persisted on every WS message (storage hot loop)** — `room-do.js:1536,1548`
    `persistEphemeralToStorage()` serializes the whole rate-limit+moderation maps per message; O(N) write + un-awaited races. → debounce / move to alarm-driven prune.

14. **Reaction INSERT placeholder/bind mismatch (always throws)** — `room-do.js:1172-1175`
    7 placeholders, 6 bound values → every add-reaction throws and degrades to "internal error". → remove the extra placeholder. *(quick, isolated fix)*

15. **`/announce` and `/stream` DO endpoints have no auth** — `room-do.js:1748,1840`
    Broadcast arbitrary events / write to D1 with caller-supplied `projectId`/`userId`, no verification. → require a service credential; don't trust body identity.

16. **CDP/support by-id lookups missing tenant scope (PII IDOR)** — `routes/cdp-http.js`, `lib/customer-data.js:45,81,125,168`, `routes/support-http.js`, `lib/enterprise-support.js`
    Auth enforced but by-id selects lack `project_id` → tenant admin reads another tenant's customer PII / tickets by ID. → scope every by-id query by `projectId`.

17. **`/webhooks/register` — any member, any URL, no SSRF check** — `routes/reports-webhooks-http.js:127-194`
    No admin gate (unlike PATCH/DELETE); stored URL later fetched → SSRF to `169.254.169.254` etc. → require admin + SSRF allowlist (block private/link-local/metadata, https only).

18. **`/upload` buffers full body before size check (DoS)** — `routes/public-http.js:200-201`
    `request.arrayBuffer()` before `MAX_FILE_SIZE` check; no Content-Length pre-check, no upload rate limit. → reject early on Content-Length, rate-limit.

19. **`activeStreams` never cleaned on disconnect** — `room-do.js:687,748,774` vs `onClose:1342-1382`
    Disconnect mid-stream leaves entry → `stream_already_active` blocks restart until DO restart. → finalize/abort on last connection close.

20. **SMS OTP: no attempt limit + TOCTOU consumption** — `lib/sms-otp-auth.js:114-144`
    No failed-attempt counter, non-atomic select-then-update → brute-force/replay. → bounded attempts + atomic `UPDATE ... WHERE consumed_at IS NULL` checking `changes===1`.

21. **SCIM tokens stored as unsalted SHA-256** — `lib/scim.js:17-24`
    Full-user-CRUD tokens crackable from a D1 dump. → use salted `hashApiKey` path.

22. **`/platform/bootstrap` references undefined `timingSafeEqual`** — `routes/public-http.js:298,343`
    `ReferenceError` → 500; secret-gated platform routes non-functional. → import `timingSafeEqual`.

23. **Webhook batch verify accepts unsigned events** — `lib/webhook-batch-verify.js:50-71`
    Missing `batchSignature` defaults `{valid:true}` → unsigned events treated authentic. → require batch or per-event signature for every event.

24. **TOTP backup codes only 32 bits; `verifyAdminTotp` no brute-force limit** — `lib/totp-2fa.js:52-56,187-205`
    Weak admin-2FA bypass codes + online guessing. → ≥10 random bytes + rate limit.

25. **SDK: stale JWT reused forever on reconnect** — `sdk/src/index.ts:729,797-808`
    `token` frozen at construction; reconnect re-serializes expired token → loop fails (except React provider path). → accept `tokenProvider` resolved per connect.

26. **SDK: `FluxyMessageStream` leaks a listener per stream** — `sdk/src/message-stream.ts:93-111`
    `bindCapture` never removed in `end()`/`abort()`. → store handler, remove on teardown.

27. **SDK: `useUserChannel` has no reconnect** — `sdk/src/use-user-channel.ts:33-64`
    Any blip → permanent silent disconnect. → resilient wrapper with backoff.

### Verified solid (not re-litigating)
- Core JWT verify (`lib/jwt-auth.js`): token-derived projectId/roles, exp required, constant-time, parameterized SQL throughout `routes/`.
- `messages-http`, `rooms`, `gdpr-http`, `admin-projects-http` consistently scope `project_id` + `canAccessRoom`.
- Dashboard: server-side JWT minting, escaped search snippets, per-request CSP nonce, constant-time ack gate, no `dangerouslySetInnerHTML` with untrusted data.
- UI: all content rendered as React text nodes + `safeUrl` scheme allowlist; AES-GCM uses fresh random IV.
