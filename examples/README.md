# Examples

Runnable apps in this folder:

- [agent-bot](./agent-bot): Node process that sits on a room WebSocket via `@fluxy-chat/agent`.

The Next.js scaffolds are not copied here. They ship with the CLI:

```bash
npx @fluxy-chat/create-fluxy-chat@latest my-room --example shared-ai-room
npx @fluxy-chat/create-fluxy-chat@latest my-war --example war-room
npx @fluxy-chat/create-fluxy-chat@latest my-deal --example deal-room
```

Templates live in `packages/create-fluxy-chat/templates/`. IoT, fleet, game, edu, and the rest are there too. Same Worker, extra starters.

Hosted is beta. Pin npm versions.
