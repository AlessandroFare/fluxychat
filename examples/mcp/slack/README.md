# Slack MCP server (FluxyChat official example)

Post messages and list channels from agent conversations. Clone, set `SLACK_BOT_TOKEN`, run.

```bash
cd examples/mcp/slack
npm install
export SLACK_BOT_TOKEN=xoxb-...
npm start
```

Catalog id in FluxyChat marketplace: `slack-mcp`.

See `examples/mcp/github/README.md` for wiring steps.
