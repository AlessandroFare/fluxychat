## Title

Multiplayer code agents: approvals, coaching, and browser handoff in one room

## Abstract (draft)

Coding agents already run tools. The missing piece is a room where two humans and an agent share a timeline, a tool call can wait for a named approver, a coach can whisper, and a Browser Run live view can be taken over without putting screenshots on the transcript. This talk shows FluxyChat’s room Durable Object as that bus: HITL maker-checker, OpenTelemetry GenAI `invoke_agent` / `execute_tool` with `fluxy.approval.wait`, and a catalog A2UI surface instead of an agent iframe.

## Demo gate

- Two-tab gallery (`deal-room` or `negotiation-room`) plus one tool approval.
- Optional: Browser Run handoff card (whisper to invoker).
- Adapter: existing agent SDK → room `invokeAgent`, not a new runtime.
