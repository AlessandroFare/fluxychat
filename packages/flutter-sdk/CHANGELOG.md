# Changelog

## 1.0.0

- Initial release
- FluxyChatClient with 80+ methods
- WebSocket with auto-reconnect (exponential backoff, max 10 attempts)
- REST API for rooms, messages, members, reactions, search
- Room connection with heartbeat, outbound queuing, waitFor
- Optimistic message delivery with server ack reconciliation
- Streaming message composition for AI agent responses
- Typing indicators, presence tracking, read receipts
- E2E encryption detection and key management
- Poll creation and voting
- File upload support
- Push notification device registration (web + mobile)
- Custom domain management
- Webhook CRUD
- Scheduled messages
- Message templates with variable substitution
- Agent queue management
- Room handoff
- Protocol parity validated against fluxy-chat/protocol
