# FluxyChat public status page (Upptime)

Zero-cost public uptime/SLA page using [Upptime](https://github.com/upptime/upptime) (MIT).

## Quick start

```bash
# 1. Create repo from Upptime template (GitHub UI → Use this template)
# 2. Copy config from monorepo
cp .upptime/config.json /path/to/fluxychat-status/.upptime/config.json

# 3. Push — GitHub Actions runs every 5 min and commits uptime history
```

Dashboard ops checklist: **Settings → Public status page** (`/settings/status`).

## Setup

1. Fork or copy this config into a dedicated repo (e.g. `fluxychat-status`).
2. Enable GitHub Actions + GitHub Pages on that repo.
3. Set `cname` in `.upptime/config.json` to your status subdomain (e.g. `status.fluxychat.com`).
4. Optional: set `NEXT_PUBLIC_STATUS_PAGE_URL=https://status.yourdomain.com` on the dashboard.

## Monitored endpoints

| Name | URL | Interval |
|------|-----|----------|
| Worker API | `https://api.fluxychat.com/health` | 5 min |
| Dashboard | `https://app.fluxychat.com/` | 5 min |
| Public demo | `https://demo.fluxychat.com/` | 15 min |

Replace URLs with your production hostnames.

## Files

- `.upptime/config.json` — sites, GitHub repo target, status page branding
- `.upptime/.github/workflows/uptime.yml` — generated by Upptime template (do not hand-edit in template repo)

## DNS

Point `status.fluxychat.com` CNAME to `&lt;org&gt;.github.io` or custom Pages URL.

## Alternative

Self-host [Gatus](https://github.com/TwiN/gatus) on a VPS if you prefer not to use GitHub Pages.
