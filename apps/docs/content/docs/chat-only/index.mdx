# Chat only

Minimal path for **in-app chat**: install the SDK, mint a JWT, wire `useChat` and optional `useInbox`. Skip stream, IoT, fleet, and spatial modules until you need them.

## Start here

1. [Chat-only quickstart](/docs/getting-started/chat-only-quickstart) — install, JWT, first message
2. [Scaffold with React](/docs/packages/react) — `npx create-fluxy-chat my-chat --template react`
3. [Inbox & notifications](/docs/guides/chat/inbox-notifications) — `useInbox`, badges, mark-read
