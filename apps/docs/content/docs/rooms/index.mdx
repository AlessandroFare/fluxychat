A room is one Durable Object plus D1. Chat, presence, occupancy, typing, locks, and cursors share the JSON WebSocket. Yjs uses a second binary connection on the same `/ws/room/:id` route.

Hosted is beta. Pin `@fluxy-chat/sdk` (see [status and limits](/docs/learn/status-and-limits)).

## Get a room

```ts
import { FluxyChatClient } from "@fluxy-chat/sdk";

const client = new FluxyChatClient({
  baseUrl: workerUrl,
  token: memberJwt,
  userId: "ada",
});

const room = await client.rooms.get("lobby");
await room.attach();
```

`client.room("lobby")` is the same object, without waiting. `await room.attach()` resolves when the socket is attached, or rejects on `suspended` / `failed`. `rooms.get` rejects if you request the same id with different options (`unable to get room; options differ`). `rooms.release("lobby")` detaches and drops the cache. `client.close()` / `rooms.dispose()` tears down every tracked room.

`useChat({ roomId })` still connects as a side effect. For attach-on-purpose, use `useChat({ roomId, autoConnect: false })` and call `attach()`, or wrap with `FluxyRoomProvider`.

## What is on the bag

| Field | Job |
| --- | --- |
| [`messages`](/docs/rooms/messages) | Send, history, edit, delete, message reactions |
| [`presence`](/docs/rooms/presence) | Enter, leave, update. Leave does not close the socket |
| [`occupancy`](/docs/rooms/occupancy) | Socket count vs unique members |
| [`typing`](/docs/rooms/typing) | Ephemeral `keystroke` / `stop` |
| [`reactions`](/docs/rooms/reactions) | Room-level bursts (`room_reaction`), not message emoji |
| [`cursors`](/docs/rooms/cursors) | Batched pointer + last-position map |
| [`locks`](/docs/rooms/locks) | Exclusive lock on the Room DO |
| [`locations`](/docs/rooms/locations) | UI locus (`uiLocation`), not GPS |
| [`members`](/docs/rooms/members) | Roster + leaver TTL |
| `objects` | Shared JSON bag (`derived` / `derived_set`) |
| [`status`](/docs/rooms/status) | Attach lifecycle |
| `onDiscontinuity` | Resume hole you could not fill |

React hooks with the same names live on `FluxyRoomProvider`: `useMessages`, `usePresence`, `useOccupancy`, `useTyping`, `useLocks`, `useCursors`, `useMembers`, `useRoomStatus`.

Dedicated pages: [Message history](/docs/rooms/history), [Message replies](/docs/rooms/replies), [Share media](/docs/rooms/media), [UI kit](/docs/rooms/ui-kit).

## Options

```ts
const room = await client.rooms.get("lobby", {
  occupancy: { enableEvents: true },
  messages: { rawMessageReactions: false },
});
```

Occupancy events default on (same socket, not a second channel). Set `enableEvents: false` if you only want `occupancy.get()`. Raw message reactions default off.
