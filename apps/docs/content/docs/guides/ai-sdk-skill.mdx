## Identity
You are coding with FluxyChat SDK (`@fluxychat/sdk`). All imports from `@fluxychat/sdk` or local `./index`. Core pattern: factory functions (`createXyz()`) returning interfaces with per-instance state.

## Modules

### Core
- **ThreadState** — `createThreadState()`, `createThreadStateComposer()`: thread management with state merging
- **Outbox** — `createOutbox()`: message queue with dedup, flush, bump
- **Transport** — `createWebSocketTransport()`, `createAdaptiveTransport()`, `createDurableTransport()`, `createWebTransport()`: WebSocket/WebTransport with backpressure
- **Sync** — `delta-sync.ts`: CRDT-like state sync with patches

### Media & Voice
- **Voice pipeline** — `createVoicePipeline()`: mic→ASR→LLM→TTS→speaker 5-stage orchestrator with per-stage metrics
- **Voice realtime** — `createRealtimeProvider()`, `createSemanticEOTDetector()`: realtime audio with WebRTC, semantic endpointing
- **Voice quality** — `createSloTracker()` (TTFA percentiles), `createNoiseProcessor()` (AEC/noise/gain), `createQualityCollector()` (snapshot breakdown)
- **Turn detection** — `createTurnDetector()`: VAD energy gate + semantic EOT, dynamic endpointing
- **Voice controls** — `createProsodyController()` (style/rate/pitch), `createDiarizer()` (speaker ID/overlap/correction)
- **Call QA** — `createQaAnalyzer()`: topic/outcome/sentiment/compliance scoring with evidence spans
- **Huddles** — `createHuddle()`: WebRTC join/leave, mute/unmute, screen share, captions, recording consent
- **Video generation** — `createVideoGenerator()`: polling progress, cancel, multi-job tracking

- **Agent-to-agent** — `createAgentToAgent()`: direct agent messaging

## Patterns
1. Factory functions only (no class exports, no module-level state)
2. Each factory returns typed interface with per-instance mutable state
3. In-memory implementations — deployer wires real infrastructure (LiveKit, Redis, MLS provider, etc.)
4. Tests use `vi.fn()` mocks, no external services
5. Guide docs in `docs/guides/*.md` with usage examples
