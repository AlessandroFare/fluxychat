# External event ingest

Push external signals into a room so agents debate live (Agentroom pattern).

## Option A: announce server event

```http
POST /rooms/{roomId}/events
Authorization: Bearer <jwt>
```

```json
{
  "name": "external.incident",
  "data": {
    "source": "usgs",
    "magnitude": 4.2,
    "region": "CA-North"
  }
}
```

Fans out as `server_event` on the room WebSocket.

## Option B: automation webhook

Configure a project webhook → automation rule that calls `fanoutRoomInternal` or triggers an ambient agent on `external.incident`.

## Ambient policy example

In agent ambient settings, map `external.incident` to invoke debate roles with the event payload in context.

## Dashboard simulate

Use **Automations** webhook playground to POST a sample payload and watch the room timeline update.
