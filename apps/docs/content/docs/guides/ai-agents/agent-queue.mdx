---
title: Agent queue
description: SLA timers, claim, and dispositions after an agent hands off to a human.
---

When an agent hands off, the Worker can park the conversation in an operator queue.

## HTTP

- `GET /agent-queue` — open items, SLA timers
- `GET /agent-queue/dispositions` — wrap-up codes shared with [handoff](/docs/guides/ai-agents/handoff)

Claim an item in the dashboard queue, talk in the same room, then set a disposition.
