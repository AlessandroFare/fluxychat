# IoT telemetry

Do **not** use MQTT. Post HTTP, listen on the room WebSocket.

```bash
npx @fluxy-chat/create-fluxy-chat@latest my-iot --example iot-panel
```

```bash
curl -X POST "$WORKER/rooms/$ROOM/iot/events" \
  -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"sim-1","eventType":"telemetry","payload":{"temp":21}}'
```

```tsx
useChat({
  roomId,
  onServerEvent: (ev) => {
    if (ev.name === "iot.reading") console.log(ev.data);
  },
});
```

See [IoT](/docs/platform/iot).
