Decision Rooms bundle workflows you already have in FluxyChat. No extra tables. You get a group room, starter templates, and links into the console tools below.

## What's included

| Feature | Console path | Purpose |
|---------|--------------|---------|
| Async quorum decisions | Room chat + `/decisions` UI | Propose, vote by role, close the decision |
| Multi-agent debate | `/agents/debate` | Technical, business, and risk perspectives |
| Counterfactual replay | `/agents/observability` | Branch agent runs with different inputs |
| Truth Market | `/truth-market` | Stake and dispute claims |

## Create from the dashboard

1. Open **Rooms** (`/rooms`).
2. Enter a display name (optional; default is "Decision Room").
3. Click **Create Decision Room** (admin JWT required).

The pack creates a `group` room, adds you as owner, seeds three templates, and posts a welcome message with links to the workflows above.

## API

| Method | Path | Description |
|--------|------|-------------|
| GET | `/packs/decision-rooms` | Preview pack metadata (public) |
| POST | `/packs/decision-rooms` | Provision room and templates (JWT) |

```json
POST /packs/decision-rooms
{ "name": "Q3 Planning" }
```

The response includes `room.id`, `templatesCreated`, and `features[]` with deep-link paths.

## Message templates

Templates use `{{variable}}` placeholders. Fill them from the template picker in chat:

- **Decision proposal**: `question`, `options`, `quorum`
- **Debate kickoff**: `topic`, `constraints`
- **Truth claim**: `claim`, `stake`
