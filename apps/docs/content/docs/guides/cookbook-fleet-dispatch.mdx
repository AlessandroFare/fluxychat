# Emergency / fleet dispatch demo

Use **Fleet** vertical plus room coordination.

1. Create ops room `dispatch-central`.
2. Subscribe to GPS updates via FluxyFleet webhooks.
3. Fan out `location_update` events to the room WebSocket (built into Room DO).
4. Agents or humans ack assignments with [Critical action quorum](/docs/guides/critical-action-quorum).

Dashboard: **Fleet** page for map view; room timeline for voice-style coordination.
