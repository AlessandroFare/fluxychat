# Built with patterns

Teams on Portal hackathons reused the same primitives:

| Pattern | Example builds |
|---------|----------------|
| Agents as room peers | AI War Room, Multiplayer AI, Agentroom |
| Agent vs agent negotiation | Altoke, AgentSync, Syncro |
| Asymmetric visibility | ReclIA, Cable Rush |
| Presence escalation | Aldaba, RestaurantFlow, SAMU |
| IoT one channel | Nexora, jikan |
| Live audience scoring | OratorIA, Vokaly Prep |
| Knowledge / decision graph | Synapse, KUSKA |
| Room exposed to external MCP | room (X-TAL) |

FluxyChat ships docs and APIs for each row. Start from [Hackathon cookbooks](/docs/guides/hackathon-cookbooks).
