# A2A agent protocol

FluxyChat implements an **A2A adapter**: fetch external **Agent Cards**, validate HTTPS endpoints, and delegate tasks to remote agents while keeping room context on your Worker.

## Console

**Agents → A2A** (`/agents/a2a`)

1. Register external agent **base URL** (Agent Card discovery).
2. **Test delegation** with a sample task payload.
3. View task status and responses in the task list.

## Complementary protocols

| Protocol | Direction |
|----------|-----------|
| **AG-UI** | Agent → user UI in chat |
| **A2A** | Agent → agent |
| **MCP** | Agent → tools |

## Security

- HTTPS-only Agent Card fetch.
- SSRF blocks on internal IPs.
- Optional `A2A_OUTBOUND_BEARER` for authenticated remote endpoints.

## API

```http
GET  /a2a/agents
POST /a2a/agents
POST /a2a/tasks
GET  /a2a/tasks/:taskId
POST /a2a/tasks/:taskId/cancel
```

Agent Card JSON follows the [Linux Foundation A2A](https://github.com/a2aproject/A2A) spec.
