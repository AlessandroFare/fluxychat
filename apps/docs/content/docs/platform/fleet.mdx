# Fleet module

Vehicles POST GPS to the Worker. The room WebSocket fans out `server_event` `fleet.gps_update`. **Not MQTT.**

```bash
npx @fluxy-chat/create-fluxy-chat@latest my-fleet --example fleet-panel
```

```bash
curl -X POST "$WORKER/fleet/gps" \
  -H "Authorization: Bearer $FLEET_DEVICE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"vehicleId":"veh_1","lat":45.46,"lng":9.18,"roomId":"demo"}'
```

```ts
useChat({
  roomId,
  onServerEvent: (ev) => {
    if (ev.name === "fleet.gps_update") {
      // ev.data.vehicleId, lat, lng, geofenceEvents (enter/exit transitions)
    }
  },
});
```

Register vehicles with `POST /fleet/vehicles` (SDK `createFleetVehicle`). The response includes `apiKey` (`fleet_…`) once. Drivers POST GPS with that key; other fleet routes still need a member JWT. OwnTracks location JSON (`_type`, `lat`/`lon`/`tst`, `acc`/`vel`/`cog`/`tid`) is accepted on the same POST (array ok; `lwt` skipped). Last/history aliases: `GET /fleet/gps/last`, `GET /fleet/gps/locations?vehicleId=&from=&to=&limit=` (`from`/`to` unix or ISO date). Default fan-out room is `fleet:{projectId}` if `roomId` is omitted. Cap: 60 GPS points per vehicle per minute. Geofences are `GET/POST/PATCH/DELETE /fleet/geofences`; stored enter/exit rows are `GET /fleet/geofence-events`. Current positions omit vehicles whose last ping is older than 10 minutes. Not MQTT.
