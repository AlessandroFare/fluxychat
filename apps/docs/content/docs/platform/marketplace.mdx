title: Marketplace
description: Agent templates, project apps, and MCP catalog on Worker HTTP.
---

Console: `/marketplace`. Agent templates: `/marketplace/agents` and `/admin/marketplace/install`. Project app manifests: `/admin/marketplace/apps` (KV, admin JWT). MCP catalog: `/marketplace/mcp-apps`.

ApyHub is a curated remote MCP. Install registers identity in the project. You still create an [ApyHub](https://apyhub.com/mcp) account and paste the EU or US HTTP MCP URL (`https://mcp.eu.apyhub.com` or `https://mcp.us.apyhub.com`). FluxyChat does not host those 1500 tools. LLM provider keys live in `/agents/llm-keys`, not in the marketplace tab.
