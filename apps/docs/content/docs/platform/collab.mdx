# Collab module

Shared presence and collaborative sessions built on room Durable Objects and platform transport.

Typical uses:

- Co-editing session chat
- Whiteboard or document room sidebars
- Multi-user operational dashboards

Connect through the standard `FluxyChatClient` room APIs; collab-specific capabilities extend room metadata and capability events (`POST /rooms/:roomId/capabilities/events`).

See [Transport](/docs/platform/transport) and [Realtime modules](/docs/platform/realtime-modules).
