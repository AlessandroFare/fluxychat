Hosted FluxyChat is open beta. Pin npm. The pages below are the modules in the console. They share one Worker, one room object, and one JSON WebSocket for events. Yjs uses a second binary socket on the same room.

Bridges (Slack, Discord, and the rest) store a binding. You still create the vendor app. That is not a finished omnichannel desk.
