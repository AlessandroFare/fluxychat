## Per-item implementation hints

### NW-100 Offline-first SDK

```
packages/sdk/src/offline/
  indexed-db-store.ts    # events + pending ops
  sync-engine.ts         # reconnect + delta apply
  types.ts
```

- Mirror Stream LLC pattern: all WS events → local DB; `sendMessage` optimistic + pending task.
- Hook into `room-session.ts` reconnect path.
- Do **not** use ElectricSQL CRDT writes — server-authoritative DO remains source of truth.

### NW-101 Live translation toggle

- Worker: on message ingest call translation if `room_translation_settings.auto_translate`.
- Store `messages.translated_text`, `messages.source_locale`.
- UI: `MessageBubble` pill toggles display field.

### NW-104 Polls UI

- API exists: `FluxyChatClient.createPoll`, `votePoll`, `getPoll`, `closePoll`.
- Add `PollComposer` + `PollResults` components under `apps/dashboard/components/chat/`.

### NW-200 Duplex room agent + on-hold

- Extend `agent-tool-policy.js`: `onHoldPhrase` per tool rule.
- Voice pipeline: when tool call starts, TTS filler via unified multimodal path; barge-in cancels (`voice-ai-pipeline.js`).
- Reference: NVIDIA Nemotron VoiceChat side-channel + OpenAI GPT-Live delegation pattern.

### NW-201 Decision Rooms

- No new backend — template in `install-template` or dashboard "Create decision room".
- Bundles: quorum enabled, debate agents, counterfactual on agent runs, truth market optional.
