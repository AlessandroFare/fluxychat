title: "D1 schema consolidation (internal)"
description: "Engineering note for FluxyChat contributors. Not part of the public integration docs."
---

This document describes how we plan to consolidate D1 migrations for faster fresh installs. It is maintained for the core team in the repository (`docs/` and `apps/worker/db/`).

If you are self-hosting FluxyChat, follow [Production setup](/docs/operations/production-setup) and apply migrations with:

```bash
cd apps/worker
pnpm exec wrangler d1 migrations apply fluxychat --remote
```

Do not wait for a consolidated baseline unless the project publishes one in release notes.
