## Quick deploy (contributors)

From repo root:

```bash
pnpm install
pnpm test
cd apps/worker && pnpm exec wrangler d1 migrations apply fluxychat --remote
pnpm exec wrangler deploy
```

Rollback and secrets detail live in the repository contributor runbook (not required for integrators). See [Production setup](/docs/operations/production-setup) for the public deploy path.
