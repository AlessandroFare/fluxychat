# 44000 — channel_at_capacity

The room hit its connection cap. Terminal for this attempt.

**At a glance** — HTTP 429 · close 1008 `channel_at_capacity` · terminal for this attempt · SDK `FluxyAuthError` with `refusalCode: "channel_at_capacity"`.

## What to do

- The credential is fine: wait and retry, or point the user at another room.
- Retrying later can succeed once other clients disconnect — it is not an auth problem.
- Do not treat it like `rate_limited`: the block is on the room's connections, not on request frequency.
