# Error codes

These codes sit on `FluxyErrorInfo.code`. The Worker still closes sockets with 1008 and a short reason (`token_expired`, `not_member`). The numeric code is for SDKs and docs.

Registry: `packages/protocol/errors/catalog.json`. Do not invent codes in app copy.
