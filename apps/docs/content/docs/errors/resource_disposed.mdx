# 40041 — resource_disposed

`rooms.get` ran after `rooms.dispose()` / `client.close()`. The client is done. Terminal.

**At a glance** — HTTP 400 · terminal · a client lifecycle error, not a network failure.

## What to do

- Create a new `FluxyChatClient` instead of reusing the disposed one.
- Terminal means retrying on the same client cannot succeed — the fix is a new client, not a retry.
