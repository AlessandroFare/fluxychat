# 40103 — anonymous_not_allowed

The room is not public: a `pk_` publishable key or a guest JWT cannot join. Terminal.

**At a glance** — HTTP 401 · close 1008 `anonymous_not_allowed` · terminal · SDK `FluxyAnonymousNotAllowedError`.

## What to do

- Connect with a member JWT minted for the user (`POST /auth/token`, roles `member`) instead of the guest path.
- A public room accepts the `pk_` path; this room does not. Either join as a member or use a room configured for anonymous access.
- The refusal is terminal — retrying the guest connection cannot succeed.
