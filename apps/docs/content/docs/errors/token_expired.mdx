# 40100 — token_expired

The JWT is expired, or it is not a Fluxy member token. Terminal: stop retrying with the same credential.

**At a glance** — HTTP 401 · close 1008 `token_expired` · terminal · SDK `FluxyTokenExpiredError`.

## What to do

- Mint a new member JWT server-side (`POST /auth/token` with the `fc_` key) and reconnect with it. Never hand-craft or reuse another environment's token.
- The SDK folds both `token_expired` and `invalid_token` closes into `FluxyTokenExpiredError`.
- For long-lived clients, rotate before expiry with `scheduleSessionTokenRefresh` instead of reconnecting on failure.
