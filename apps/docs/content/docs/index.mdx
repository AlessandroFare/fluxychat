FluxyChat is the collaboration layer for your app: a Cloudflare room (Durable Object + D1) where people and agents share one WebSocket. Auth stays yours. Map `roomId` to a document, board, deal, classroom, or dispatch view.

Start with `npx @fluxy-chat/create-fluxy-chat@latest`, then [Concepts](/docs/concepts) if you want the mental model, or [What to build](/docs/getting-started/what-to-build) if you already know the product.

## What you need

| Piece | Who sets it |
|-------|-------------|
| Worker URL | Hosted API or your `workers.dev` |
| Project API key (`fc_…`) | Server only. Mints JWTs. |
| Member JWT | Your backend to the SDK (or guest join) |
| LLM keys | Worker secrets. Never the browser. |

Try [fluxychat.com](https://fluxychat.com). Self-host: `pnpm install && pnpm run self-host && pnpm --filter @fluxy-chat/worker dev`.
