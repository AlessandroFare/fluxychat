## What you need

| Piece | Who sets it |
|-------|-------------|
| Worker URL | Hosted API or your `workers.dev` |
| Project API key (`fc_…`) | Server only. Mints JWTs. |
| Member JWT | Your backend → SDK |
| LLM keys | Worker secrets. Never the browser. |

Try [fluxychat.com](https://fluxychat.com). Contributors: `pnpm install && pnpm run self-host && pnpm --filter @fluxy-chat/worker dev`.
