# Chat UI in three lines

`@fluxy-chat/ui-kit` closes the gap between headless SDK hooks and a production-ready chat surface. Built on `@fluxy-chat/ui` + `@fluxy-chat/react`.

## Install

```bash
pnpm add @fluxy-chat/ui-kit @fluxy-chat/ui @fluxy-chat/react @fluxy-chat/sdk
```

## FluxyChatWidget

```tsx
import { FluxyChatWidget } from "@fluxy-chat/ui-kit";

export function SupportChat({ jwt }: { jwt: string }) {
  return (
    <FluxyChatWidget
      roomId="support"
      workerUrl={process.env.NEXT_PUBLIC_FLUXYCHAT_WORKER_URL!}
      token={jwt}
      theme="brand"
      height={520}
      title="Support"
    />
  );
}
```

Props: `roomId`, `workerUrl` + `token`, or pre-built `client` shared with inbox.

## FluxyInboxPanel

```tsx
import { FluxyInboxPanel } from "@fluxy-chat/ui-kit";

<FluxyInboxPanel
  workerUrl={workerUrl}
  token={jwt}
  onSelectItem={(item) => openRoom(item.roomId)}
  height={400}
/>
```

Shows unseen badge, room list, realtime `onItem` via `useInbox`.

## CLI scaffold (fastest path)

```bash
npx create-fluxy-chat my-chat --minimal
```

Generates Vite + `FluxyChatWidget` only — no Worker platform modules.

## Optional: assistant-ui bridge

```bash
pnpm add @assistant-ui/react
```

```tsx
import { useExternalStoreRuntime, Thread } from "@assistant-ui/react";
import { useFluxyAssistantRuntime } from "@fluxy-chat/ui-kit";

const { externalStoreProps } = useFluxyAssistantRuntime({ roomId, client });
const runtime = useExternalStoreRuntime(externalStoreProps);
return <Thread runtime={runtime} />;
```

## Themes

Pass `theme`: `default` | `dark` | `minimal` | `brand` — same presets as `@fluxy-chat/ui`.

## When to use ui-kit vs hooks

| Need | Package |
|------|---------|
| Full layout control, custom design system | `@fluxy-chat/react` + `@fluxy-chat/ui` primitives |
| Ship chat in minutes | `@fluxy-chat/ui-kit` |
| Headless / non-React | `@fluxy-chat/sdk` |
