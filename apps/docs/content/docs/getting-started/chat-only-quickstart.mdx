# Chat-only quickstart

Use this path when you want **in-app chat only** — not stream, IoT, fleet, or spatial modules.

## Fastest: ui-kit or minimal CLI

**Drop-in widget (3 lines):**

```bash
pnpm add @fluxy-chat/ui-kit
```

```tsx
import { FluxyChatWidget } from "@fluxy-chat/ui-kit";

<FluxyChatWidget roomId="general" workerUrl={url} token={jwt} theme="brand" height={520} />
```

See [@fluxy-chat/ui-kit](/docs/packages/ui-kit).

**Scaffold:**

```bash
npx create-fluxy-chat my-chat --minimal
```

## Headless: SDK hooks

### Install

```bash
pnpm add @fluxy-chat/sdk @fluxy-chat/react
```

Import only chat hooks (keeps your bundle small):

```tsx
import { FluxyChatClient } from "@fluxy-chat/sdk";
import { FluxyRealtimeProvider, useChat } from "@fluxy-chat/react";
```

### Client + JWT

**Hosted (fastest):** sign up → **Onboarding** → copy Worker URL + member JWT.

**Local:** from repo root:

```bash
pnpm install && pnpm run first-message
```

### Three lines to live chat

```tsx
"use client";

import { FluxyChatClient } from "@fluxy-chat/sdk";
import { FluxyRealtimeProvider, useChat } from "@fluxy-chat/react";

const client = new FluxyChatClient({
  baseUrl: process.env.NEXT_PUBLIC_FLUXYCHAT_WORKER_URL!,
  userId: "user-1",
  token: process.env.NEXT_PUBLIC_FLUXYCHAT_MEMBER_JWT!,
});

export function ChatPanel({ roomId }: { roomId: string }) {
  const { messages, sendMessage, connectionState } = useChat({
    roomId,
    client,
    markReadLatest: true,
  });

  return (
    <FluxyRealtimeProvider client={client}>
      <p>Status: {connectionState.status}</p>
      <ul>
        {messages.map((m) => (
          <li key={m.id}>{m.content}</li>
        ))}
      </ul>
      <button type="button" onClick={() => sendMessage("Hello")}>
        Send
      </button>
    </FluxyRealtimeProvider>
  );
}
```

### Optional: AI agent in the same room

Mention an agent configured in the console:

```tsx
await sendMessage("@assistant How can you help?");
```

Streaming replies use the same WebSocket — see [Agents guide](/docs/guides/agents).

### Inbox

```tsx
import { useInbox } from "@fluxy-chat/react";

const { items, unreadCount, markRead } = useInbox({ client });
```
