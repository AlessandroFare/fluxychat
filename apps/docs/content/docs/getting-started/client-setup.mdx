FluxyChat clients talk to **your Worker URL**. Public rooms: `publishableKey` on `FluxyRealtimeProvider`, or `joinPublicRoomAsGuest`. Private rooms need a **member JWT**. `fc_` keys stay on the server. **React is the flagship client.** Vue and Svelte packages exist on npm as best-effort. React Native is on npm. Flutter/Swift/KMP stay in-repo until pub.dev/CocoaPods.

<Tabs items={["Guest", "React", "Vanilla JS", "React Native", "Flutter"]}>
  <Tab value="Guest">

```tsx
import { FluxyRealtimeProvider, useChat } from "@fluxy-chat/react";

<FluxyRealtimeProvider workerUrl={workerUrl} publishableKey="pk_...">
  <Room />
</FluxyRealtimeProvider>

function Room() {
  const { messages, sendMessage } = useChat({ roomId: "general" });
}
```

The room must be **public**. The SDK mints an anonymous guest JWT. Without a `pk_` (self-host + `PUBLIC_GUEST_ENABLED`):

```ts
import { FluxyChatClient } from "@fluxy-chat/sdk";

const session = await FluxyChatClient.joinPublicRoomAsGuest(workerUrl, publicRoomId, {
  displayName: "Ada",
});
```

Production apps mint JWTs after sign-in ([Auth JWT](/docs/guides/auth-jwt)).

  <Tab value="React">

```bash
pnpm add @fluxy-chat/react
```

```tsx
import { FluxyRealtimeProvider, useChat } from "@fluxy-chat/react";

function App({ workerUrl, memberJwt }: { workerUrl: string; memberJwt: string }) {
  return (
    <FluxyRealtimeProvider workerUrl={workerUrl} authTokenProvider={memberJwt}>
      <Room roomId="general" />
    </FluxyRealtimeProvider>
  );
}

function Room({ roomId }: { roomId: string }) {
  const { messages, sendMessage, connectionState } = useChat({ roomId });
  // render messages…
}
```

`FluxyRealtimeProvider` takes `workerUrl` plus `publishableKey`, `authTokenProvider` (JWT string or function), or `connectUrl`. There is no `client` prop.

See [@fluxy-chat/react](/docs/packages/react) and [useChat](/docs/core/use-chat).

  <Tab value="Vanilla JS">

```bash
pnpm add @fluxy-chat/sdk
```

```ts
import { FluxyChatClient } from "@fluxy-chat/sdk";

const client = new FluxyChatClient({
  baseUrl: "http://127.0.0.1:8787",
  userId: "alice",
  token: memberJwt,
});

const conn = client.connectRoom("general");
conn.onMessage((msg) => console.log(msg));
await conn.send({ text: "Hello" });
```

See [@fluxy-chat/sdk](/docs/packages/sdk) for connection state, inbox, and agents.

## Auth

Guest for public rooms (`publishableKey` or `joinPublicRoomAsGuest`). Member JWTs from your backend for everything else. Never embed `fc_…` in client bundles. Refresh with `client.setToken()` / `updateToken()`. See [Auth JWT](/docs/guides/auth-jwt).

## Common errors

| Error | Fix |
|-------|-----|
| `401 Unauthorized` | Token expired or wrong signing key. Mint a fresh JWT. |
| `not a member` | Add the user to the room via REST or dashboard |
| WebSocket blocked | Check CORS / custom domain; try HTTP long-poll fallback |

More: [Troubleshooting](/docs/reference/troubleshooting).
