# First message

Two ways. CLI if you want an app on disk. React snippet if you already have a Next/Vite project.

## A. CLI (hosted)

```bash
npx @fluxy-chat/create-fluxy-chat@latest my-app --mode hosted -y
cd my-app
pnpm install
pnpm setup:hosted
pnpm dev
```

Open http://localhost:5173, finish the tour, sign in. Mention `@assistant` in the room.

Self-host instead? [Choose your path](/docs/getting-started/choose-your-path).

## B. React in an existing app

```bash
pnpm add @fluxy-chat/sdk @fluxy-chat/react
```

`FluxyRealtimeProvider` takes `workerUrl` and `authTokenProvider`, not a `client` prop.

```tsx
import { FluxyRealtimeProvider, useChat } from "@fluxy-chat/react";

function Room({ roomId }: { roomId: string }) {
  const { messages, sendMessage, connectionState } = useChat({ roomId });

  return (
    <div>
      <p>Status: {connectionState.status}</p>
      <ul>
        {messages.map((m) => (
          <li key={m.id ?? m.clientMessageId}>{m.content}</li>
        ))}
      </ul>
      <button type="button" onClick={() => sendMessage("Hello")}>
        Send
      </button>
    </div>
  );
}

export function App({ workerUrl, jwt }: { workerUrl: string; jwt: string }) {
  return (
    <FluxyRealtimeProvider workerUrl={workerUrl} authTokenProvider={jwt}>
      <Room roomId="general" />
    </FluxyRealtimeProvider>
  );
}
```

Mint `jwt` on your server with `POST /auth/token` and a project API key (`fc_…`). See [Auth JWT](/docs/guides/auth-jwt).

Local clone of this repo: `pnpm run first-message` prints a Worker URL and JWT for `dev-local-general`.
