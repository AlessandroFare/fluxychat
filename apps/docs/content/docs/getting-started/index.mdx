## Hosted

```bash
npx @fluxy-chat/create-fluxy-chat@latest my-app --mode hosted -y
cd my-app && pnpm install && pnpm setup:hosted && pnpm dev
```

Console: [fluxychat.com/dashboard](https://fluxychat.com/dashboard). Then open two tabs.
