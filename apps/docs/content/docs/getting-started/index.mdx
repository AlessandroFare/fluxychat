If you have never used FluxyChat, start here. You need a **Worker URL** and a **member JWT**. Hosted gives you both after sign-in. Self-host means you run the Worker on Cloudflare.

## Hosted

1. `npx @fluxy-chat/create-fluxy-chat@latest my-app --mode hosted -y`
2. `cd my-app && pnpm install && pnpm setup:hosted && pnpm dev`
3. Sign in with Clerk. We create the project, room, and `@assistant`.

Console: [fluxychat.com/dashboard](https://fluxychat.com/dashboard). Playground (no signup): [fluxychat.com](https://fluxychat.com).
